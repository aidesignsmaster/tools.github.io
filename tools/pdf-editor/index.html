Online PDF Editor

This online PDF editor lets you change a PDF without installing software. Add text, highlight important lines, cover content with a white box, draw, insert an image or signature, rotate pages, delete or duplicate pages, reorder them, merge another PDF, extract selected pages, add page numbers and add a text watermark.

Your PDF is processed locally in your browser, so your documents are not uploaded to a server. The tool loads its PDF libraries once when you open a file, so an internet connection is needed the first time.

How to Edit a PDF

  1. 1

    Upload Your PDF

    Select a PDF or drag and drop it. Every page appears as a thumbnail.

  2. 2

    Edit Pages and Content

    Rotate, move, duplicate or delete pages. Select the pencil on a page to add text, highlights, drawings or a signature. Add page numbers or a watermark if you need them.

  3. 3

    Download

    Select Download PDF for the full document, or select pages and choose Download Selected Pages to save only those.

PDF Editing Uses

Typical jobs include signing a form, filling in a document with text, hiding sensitive details with a white box, removing pages, rotating scanned pages, combining several PDFs or images into one file and numbering pages of a report.

Text added in this editor uses a standard font and supports Latin letters, numbers and common symbols. For other scripts, add the text as an image. Existing text in a PDF cannot be rewritten; use Whiteout and add new text on top. A white box covers content visually, so for highly sensitive redaction use a dedicated redaction tool.

Frequently Asked Questions

What can I do with this PDF editor?

You can add text, highlights, white boxes, rectangles, drawings, images and signatures, rotate, move, duplicate and delete pages, merge PDFs and images, extract pages, add page numbers and a watermark, and edit the title and author.

Is my PDF uploaded to a server?

No. Your PDF is processed in your browser. The tool only downloads its PDF libraries when you open a file.

Can I edit existing text in a PDF?

Existing text cannot be rewritten directly. You can cover it with Whiteout and add new text on top.

How do I sign a PDF?

Open a page with the pencil button, choose Image / Signature, pick a picture of your signature, and click where it should go. You can also use Draw to sign with your mouse or finger.

How do I merge PDF files?

Open your first PDF, select Add PDF / Images to add more PDFs or images, arrange the pages, then download the combined PDF.

How do I extract pages from a PDF?

Tick the pages you want and select Download Selected Pages to save only those pages as a new PDF.

Does it work with password-protected PDFs?

Password-protected PDFs cannot be opened. Remove the password first, then upload the file.

Which languages can I type in?

Added text supports Latin letters, numbers and common symbols. For other scripts, add the text as an image.

Is this PDF editor free?

Yes. Working Tools Box provides this PDF editor free of charge, with no sign-up and no watermark.
