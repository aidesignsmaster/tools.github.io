Reduce PDF File Size, Free

This free PDF compressor shrinks a PDF's file size by redrawing every page at a chosen quality level and rebuilding a new, smaller PDF, entirely in your browser. It works as an online PDF size reducer and file shrinker, and is especially effective on scanned documents, photo-heavy reports, and PDFs exported with large embedded images, since most of their size lives in that image data.

Use it to shrink a PDF before emailing it, fit a file under an upload size limit, or save storage space. Because each page is redrawn as an image, the compressed file will look the same but will no longer have selectable or searchable text — if you need to keep that, do not compress that particular file.

Frequently Asked Questions

Is my PDF uploaded to a server?

No. The PDF is opened, compressed and rebuilt entirely in your browser, and the file is never uploaded anywhere.

Will my PDF's text still be selectable after compressing?

No. Each page is redrawn as an image to shrink file size, so the compressed PDF will look the same but its text will no longer be selectable or searchable. If you need to keep selectable text, do not use this tool on that file.

What kind of PDF compresses best with this tool?

Scanned documents, photo-heavy PDFs, and exported PDFs with large embedded images typically shrink the most, since most of their size is in image data.

Can I open a password-protected PDF?

No. Password-protected or encrypted PDFs cannot be opened by this tool. Remove the password first using your PDF viewer, then try again.

Is this free to use?

Yes, completely free with no sign-up and no watermark, since all processing happens on your own device.
