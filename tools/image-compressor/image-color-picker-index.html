Pick a Color From an Image

Image Color Picker makes it easy to identify colors from photos, graphics, screenshots, logos and other images. Upload your image, move over the area you want to inspect, and click to get the exact pixel color. The tool provides HEX, RGB, HSL and CMYK values that you can copy into design and web projects.

Frequently Asked Questions

How do I pick a color from an image?

Upload an image and click any point on the image. The selected pixel color and its color codes will appear instantly.

Which color formats are available?

The tool provides HEX, RGB, HSL and CMYK values for the selected color.

Can I use this tool for photos and screenshots?

Yes. You can use it with common image formats such as JPG, PNG, WebP and GIF.

Are my images uploaded to a server?

No. The image is processed locally in your browser and does not need to be uploaded to a server.
