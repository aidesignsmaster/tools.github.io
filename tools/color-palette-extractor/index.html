Extract a Color Palette From Any Image, Free

This free color palette extractor analyzes an image using median-cut color quantization to find its most representative colors, then presents them as a clean palette with hex, RGB and HSL codes. Choose how many colors to extract, sort them by frequency, hue or brightness, and export the result as CSS custom properties, JSON, or a downloadable PNG swatch strip.

Use it to pull a brand color palette from a logo, find complementary colors for a design from a reference photo, or document the color scheme used in an image. Everything runs locally in your browser using the Canvas API, so your image is never uploaded anywhere.

Frequently Asked Questions

Is my image uploaded to a server?

No. The palette is extracted locally in your browser using the Canvas API, and your image is never uploaded anywhere.

How many colors can I extract?

Choose anywhere from 3 to 10 colors using the slider before extracting.

What export formats are available?

You can copy the palette as CSS custom properties, as JSON, copy individual hex codes, or download a PNG swatch strip.

How does the color extraction work?

It uses a median-cut color quantization algorithm, which groups similar pixel colors together and picks a representative color for each group.

Is this free to use?

Yes, completely free with no sign-up and no limit, since all processing happens on your own device.
